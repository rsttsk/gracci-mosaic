# Мастерская мозаики Ирины Грачевой

Одностраничный сайт на React и Vite. Фотографии находятся в `public/images/`.

## Публикация на GitHub Pages

1. Загрузите содержимое архива в корень репозитория и сохраните изменения в ветку `main`.
2. В репозитории откройте **Settings → Pages** и выберите **GitHub Actions** в разделе **Build and deployment → Source**.
3. Откройте вкладку **Actions** и дождитесь завершения workflow **Deploy site to GitHub Pages**.
4. Адрес опубликованного сайта появится в **Settings → Pages**.

После первой настройки каждый новый commit в `main` автоматически соберёт и опубликует обновление.

## Локальный запуск

```sh
npm ci
npm run dev
```

Проверки перед публикацией:

```sh
npm run lint
npm run build
```
